# skill-package

The ASK CLI project for the bridge Alexa Skill. `ask-resources.json` at the repo root points here.

- `skill.json`: the Alexa Skill manifest. `npm run skill:deploy` writes the Lambda ARN (from `.env`, where `npm run deploy` put it) into `apis.custom.endpoint.uri` and runs `ask deploy` from the repo root. That edit stays local; the pre-commit hook refuses it.
- `interactionModels/custom/<locale>.json`: generated by `npm run generate`. Never edit by hand.
- `overrides/<locale>.utterances.json`: your own sample utterances, merged on every generate. Keys are intent names.

`npm run skill:deploy` also records the new Alexa Skill id in `.env` as `BRIDGE_SKILL_ID`. Optional but recommended: run `npm run deploy` again so the Lambda only accepts requests from your Alexa Skill.
