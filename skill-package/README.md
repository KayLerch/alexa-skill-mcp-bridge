# skill-package

The ASK CLI project for the bridge skill. `ask-resources.json` at the repo root points here.

- `skill.json`: the skill manifest. Put the Lambda ARN from `npm run deploy` into `apis.custom.endpoint.uri`, then run `ask deploy` from the repo root.
- `interactionModels/custom/<locale>.json`: generated by `npm run generate`. Never edit by hand.
- `overrides/<locale>.utterances.json`: your own sample utterances, merged on every generate. Keys are intent names.

After `ask deploy` prints the skill id, put it into `bridge.config.ts` as `skill.id` and run `npm run deploy` again so the Lambda only accepts requests from your skill.
