# History

- [execution-plan.md](execution-plan.md) — the build order, phases and gates, written 2026-09-03.

against these two files, and the reasoning in them explains why parts of the design look the way they do.

What outlived them is maintained elsewhere and should be read there instead: the decision table and the
verification log in [../decisions.md](../decisions.md), the design in [../architecture.md](../architecture.md),
the config reference in [../config.md](../config.md), and the setup in [../../README.md](../../README.md).
