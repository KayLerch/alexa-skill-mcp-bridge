# Decisions and verification log

Two records, both append-only. **Decisions** are the choices the design left open, each with the
reason it went that way and the condition that would change it. **Verification** is what was measured
against live SDKs and AWS, with dates and versions, because most of it is not written down anywhere else.

Both were kept in the execution plan while the project was being built; they moved here when the plan
was frozen ([docs/history/](history/)). [architecture.md](architecture.md) summarises the few that
shape the code most and links back here for the rest.

Adding to either: append a row, never rewrite one. A decision that gets reversed gets a new row saying
so, so the reasoning stays readable in order.
